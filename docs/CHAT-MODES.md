# 陌生人好友私聊与群聊

需要额外配置 AstrBot：QQ / OneBot 适配器、接收 / 触发策略、好友申请处理、模型提供方、群白名单、每群 / 每用户会话范围和限额。单纯装好桥接不等于这些功能已经启用。

## 两种回复链路

1. **DSH 桥接回复**：按桥接的 `/dsh`、private_passthrough、allow_users、allow_groups 等配置把消息交给 DSH。使用 DSH 中已有的模型与密钥，不必再复制模型凭据。但放行该链路可能允许用户请求 DSH 工具，默认只对管理员开放。
2. **AstrBot 普通聊天**：由 AstrBot 自己的模型和人格回复陌生人 / 群消息，不自动获得 DSH 的工具能力。需在 AstrBot 中配置模型提供方与触发方式。可以复用自己已有、适用于该提供方的 DSH API key，但应自行填写；登录态或临时 OAuth token 不等于普通 API key。

## 人格复用

可以把自己的 AGENTS.md 中适合聊天的规则整理到 AstrBot 人格中；也可以将本插件配置的工作区指向自己确认要共用的 DSH 工作区。本项目不会自动读取任意 DSH 工作区、导出凭据或替你开放陌生人权限。不要把凭据放入人格或长期记忆文件。

## 陌生人记录

记忆图的 owner / stranger 是管理视角的来源分类，不是多租户权限系统。不要把陌生人的私人聊天直接混进主人共享记忆。群内对话是否复用上下文由 AstrBot / 官方桥接配置决定，不能只靠脑图分区实现隔离。

限额扩展见 [ADDON.md](ADDON.md)。好友申请也须按 AstrBot 当前版本和对应适配器配置，公开版不会自动批准任何账号。
